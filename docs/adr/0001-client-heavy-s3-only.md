# ADR-0001：客户端重、必需的服务端只有 S3 兼容存储

- 状态：已接受
- 日期：2026-10-29

## 背景

目标用户是自托管的个人开发者，希望用自己的存储、一条命令部署，并且不必运维一个持续演进的后端服务。

## 决定

同步逻辑全部在客户端。必需的服务端只有 S3 兼容存储（RustFS、Garage、SeaweedFS，或 AWS S3、R2、OSS 等），自建时加 Caddy 提供 HTTPS。并发控制依赖 S3 条件写（`If-None-Match` / `If-Match`），不支持时降级为乐观并发。

配对码、每设备独立凭证、推送转发和 Web 界面由可选的 `workroam-server` 提供；它不参与同步，看不到明文，不部署时其余功能完整可用。

## 后果

- 部署与运维极简，可以直接使用已有对象存储。
- 首次初始化必须探测存储能力，并为不支持条件写的存储提供降级路径。
- 不部署服务端时，设备共用一把工作区密钥；移除设备通过密钥轮换实现。
