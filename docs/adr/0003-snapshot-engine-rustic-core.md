# ADR-0003：快照引擎使用 rustic_core

- 状态：已接受
- 日期：2026-10-29

## 背景

推送需要内容寻址分块、去重、客户端加密、快照历史和断点续传。这些能力的任何缺陷都可能导致数据丢失，必须使用成熟实现。

## 决定

使用 rustic_core（restic 兼容格式的 Rust 实现），锁定版本；在 `workroam-snapshot` crate 中定义 `SnapshotEngine` 接口，业务代码只依赖接口。存储后端通过 OpenDAL 接入，与其余存储访问一致。

## 后果

- 可直接编译进单文件二进制。
- 用户数据不会被锁死：即使 Workroam 不可用，也能用 restic 读取仓库。
- 恢复密钥实现为仓库中额外的密钥文件，修改密码无需重新加密数据。
- rustic_core 尚未 1.0，升级需经过集成测试与故障注入测试。
