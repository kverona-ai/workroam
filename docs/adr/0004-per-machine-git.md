# ADR-0004：每台机器自有 `.git`，代码通过 git 自身传递

- 状态：已接受
- 日期：2026-10-29

## 背景

跨系统直接同步 `.git` 目录会遇到配置冲突（`core.filemode`、`core.ignorecase`）、索引锁、worktree 绝对路径等问题，甚至损坏仓库；内网仓库也只能在能访问内网的设备上推送。

## 决定

不对 `.git` 目录做文件级同步。每个仓库从三种模式中选择一种：

- `bundle`：通过 git bundle 经存储传递提交（内网仓库默认）；
- `remote`：通过 origin 或中转远端传递；
- `files`：只同步工作区。

未提交改动用临时索引生成 WIP 提交带走。`bundle` 模式支持 `full`、`recent:N`、`snapshot` 三种历史档位，后两者通过重建提交与加密保存的映射表，在回到内网设备时变基回真实历史。所有 git 操作调用本机 git 命令行。

## 后果

- git 行为与用户本地完全一致。
- 需要维护“上次交换点”与重建提交映射表。
- stash、hooks、未选中的分支、`.git/config` 不会被带走，需要在文档中说明。
