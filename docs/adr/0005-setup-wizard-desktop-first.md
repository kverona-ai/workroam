# ADR-0005：首次初始化以桌面向导为主，命令行等价

- 状态：已接受
- 日期：2026-10-29

## 背景

首次初始化要完成：连接存储、选择密钥权限方式、选择或新建存储桶、十余项能力检查、设置加密密码并保存恢复密钥、本机设置、生成配对码。步骤多、只做一次、出错代价高。

## 决定

- 桌面应用首次启动时打开初始化向导，作为主要入口：逐步呈现、可回退，检查结果逐项实时刷新，恢复密钥必须确认已保存，配对码可显示为二维码。
- `workroam setup` 提供相同步骤：交互式问答，或通过参数非交互执行，用于无图形界面的机器和批量部署。
- 两者都调用 `workroamd` 的 `setup.*` 方法，由 `workroam-setup` crate 提供同一套步骤与检查注册表；`workroam doctor` 与桌面“检查”页复用同一注册表。
- 只有在最后一步才写入存储与本机配置，中途退出不留下远端对象。

## 后果

- 初始化体验一致，检查逻辑只有一份。
- 每个检查项都要提供面向用户的修复建议文本（中英双语）。
- 非交互模式需要安全地接收密钥与密码（标准输入或环境变量），并把恢复密钥写到指定文件。
- 初始化之外的功能同样遵循“两端对等”，见 [ADR-0008](0008-desktop-cli-feature-parity.md)。
