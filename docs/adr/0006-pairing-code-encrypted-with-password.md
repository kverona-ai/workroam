# ADR-0006：配对码用工作区加密密码保护

- 状态：已接受
- 日期：2026-10-29

## 背景

新设备加入工作区需要端点、桶、前缀和访问密钥。必需的服务端只有 S3，没有地方兑换短配对码；而新设备本来就需要用户输入加密密码才能解锁仓库。

## 决定

配对码 = `wr1:` + Base32（盐 + 随机数 + XChaCha20-Poly1305 密文），密钥由 scrypt(加密密码, 盐) 派生，明文为连接信息与访问密钥。新设备只需要配对码和加密密码。部署 `workroam-server` 时，额外提供 6 位一次性配对码与每设备独立凭证。

## 后果

- 不需要任何服务端即可安全配对；配对码截图泄露，没有加密密码也无法使用。
- 修改加密密码后，旧配对码随之失效。
- 不部署服务端时，所有设备共用一把工作区密钥，移除设备依赖密钥轮换（见架构文档 §8.3）。
