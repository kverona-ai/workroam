# Workroam 高保真原型

基于 [PRD](../prd.md) 的桌面应用高保真、可点击原型，视觉风格参考 Apple Liquid Glass：半透明玻璃材质、背景模糊、镜面高光边缘，支持浅色与深色。

设计数值与规则（同心圆角、阴影代替边框、间距、字体、图标、动效）见 [DESIGN.md](DESIGN.md)。

## 打开方式

直接用浏览器打开 [`index.html`](index.html)。单文件、无构建步骤，只从 Google Fonts 加载等宽字体（离线时自动回退到系统等宽字体）。右上角按钮切换外观：跟随系统 / 浅色 / 深色。

## Logo

| 文件 | 用途 |
| --- | --- |
| [`assets/logo.svg`](assets/logo.svg) | 应用图标与项目 Logo（同时替换了 `docs/assets/logo.svg`） |
| [`assets/logo-mono.svg`](assets/logo-mono.svg) | 单色模板图标，用于菜单栏 / 系统托盘，颜色跟随 `currentColor` |

**概念：**

- **W 形路线**：公司电脑 → 你的存储 → 家里电脑，字母 W 本身就是一次接力的路径；
- **两端圆环**：加入工作区的两台设备，一蓝一绿；
- **琥珀色光点**：你的工作区，沿路线移动，同一时间只在一台机器上被写入（租约）；
- **玻璃底板**：透亮但不透明，对应端到端加密。

**色彩：** Roam Blue `#2F6BFF` → Lagoon `#1FB6E8` → Mint `#2ED3B7` 组成“路线”渐变；Baton Amber `#FFB547` 只用于表示工作区与租约。
