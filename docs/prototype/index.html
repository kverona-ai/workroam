Workroam

带着 AI Agent 工作区，在每台电脑之间漫游。

W 形路线：公司电脑 → 你的存储 → 家里电脑。字母 W 本身就是一次接力的路径。

两端圆环是加入工作区的设备，一蓝一绿，代表两种系统、两个地点。

琥珀色光点是你的工作区。它沿路线移动，同一时间只在一台机器上被写入，这就是租约。

玻璃底板：透亮但不透明，对应端到端加密，存储里只有密文。

    访问密钥

    填写存储的 Access Key 与 Secret。

    密钥只保存在 macOS 钥匙串，不写入任何配置文件，也不会同步到其他设备。

    密钥权限方式

    Workroam 只需要访问工作区所在的桶。选择如何满足最小权限。

    这把密钥能访问账号下全部 7 个桶。建议在存储控制台把它的策略收窄到工作区所在的桶，或者改选“创建专用密钥”。

    存储不支持创建密钥时，第一项会自动隐藏。

    存储桶

    工作区放在哪个桶里。可以和其他数据共用一个桶，用前缀隔开。
