欢迎使用 Workroam

    欢迎使用 Workroam

    这台 Mac 还没有加入工作区。工作区是你的全部同步数据，放在你自己的 S3 兼容存储里。

    没有图形界面的机器：在终端运行 workroam setup，步骤相同。

    连接存储

    选择存储类型，Workroam 会自动识别地址风格与区域。

    HTTPS 证书有效 地址风格：路径风格（自动识别） 区域：us-east-1（自动）
    还没有部署？在你的服务器上运行这条命令，完成后会打印管理员凭证和这里要填的端点。
    ./install.sh --domain s3.home.example --storage rustfs

    访问密钥

    填写存储的 Access Key 与 Secret。

    密钥只保存在 macOS 钥匙串，不写入任何配置文件，也不会同步到其他设备。

    密钥权限方式

    Workroam 只需要访问工作区所在的桶。选择如何满足最小权限。

    这把密钥能访问账号下全部 7 个桶。建议在存储控制台把它的策略收窄到工作区所在的桶，或者改选“创建专用密钥”。

    存储不支持创建密钥时，第一项会自动隐藏。

    存储桶

    工作区放在哪个桶里。可以和其他数据共用一个桶，用前缀隔开。

    workroam-macbook-7f3a
    workroam-<设备名>-<4 位随机>，避免全局重名

    能力检查

    逐项确认这个存储能安全地承载工作区。

    加密

    数据在这台电脑上加密后才上传。加密密码用来解锁工作区，新设备加入时也要输入它。

    恢复密钥
    忘记加密密码时，只能用它解锁工作区。Workroam 没有任何办法替你找回。
    确认已保存：输入第 3 组和第 6 组
    两组都正确后才能继续。

    wrm1:7Hq2Lx…9fKe2Q
    只读设备只能拉取查看，不能推送或持有租约，适合临时借用的电脑

    移除这台设备？

    Workroam 会轮换工作区密钥，把新密钥加密分发给其余设备，然后吊销旧密钥。被移除的设备随即失去访问权限。

    那台电脑上的本地文件不受影响。

    把 payment-gateway 恢复到快照 #124？
